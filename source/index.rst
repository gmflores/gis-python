===============================================================
Cartografia con Python para Ciencias Marinas
===============================================================

Bienvenido al material oficial del curso **Cartografia y Analisis Espacial con Python para Ciencias Marinas**.

Este curso intensivo de **20 horas cronologicas** (10 sesiones de 2 horas) esta disenado para estudiantes e investigadores de posgrado en ciencias del mar sin experiencia previa en programacion, brindando las herramientas necesarias para transformar datos oceanograficos en figuras cartograficas con calidad de publicacion cientifica.
