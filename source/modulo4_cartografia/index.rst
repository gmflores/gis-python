===============================================================
Modulo IV: Cartografia Avanzada para Publicacion y Proyecto Final
===============================================================

Este modulo final culmina el aprendizaje dotando a los estudiantes de la maestria con las habilidades para componer mapas listos para someter a revistas cientificas internacionales (JCR). Se aprende el uso de Cartopy para proyecciones geodesicas, el uso de paletas perceptualmente uniformes con `cmocean`, elementos cartograficos rigurosos (escalas graficas, flechas de norte, minimapas de ubicacion) y la exportacion a formatos de alta fidelidad editorial (TIFF, PDF, SVG).
