===============================================================
Modulo II: Manejo y Mapeo de Datos Vectoriales
===============================================================

Este modulo introduce el paradigma vectorial para representar elementos discretos marinos (estaciones de muestreo, boyas meteorologicas, linderos de Zonas Economicas Exclusivas, lineas de costa y contornos de Areas Marinas Protegidas). Se abordan las relaciones topologicas, la gestion de proyecciones geodesicas y la elaboracion de mapas tematicos.
